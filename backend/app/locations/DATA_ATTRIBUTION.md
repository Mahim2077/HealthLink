# Bangladesh administrative-area data

The bundled district and upazila reference files come from the
Bangladesh Administrative Divisions dataset by Open Admin Data:

- Source: https://github.com/open-admin-data/bangladesh-administrative-divisions
- License: CC BY 4.0
- Dataset snapshot: 2026-09-08

HealthLink exposes only area codes and bilingual names to clients. Geographic
coordinates remain server-side and are used solely for approximate proximity
calculations.
